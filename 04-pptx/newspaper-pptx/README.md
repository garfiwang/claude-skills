# 新聞報紙排版風格單頁 PPTX 技能 (newspaper-pptx)

[![Version: v1.1.0](https://img.shields.io/badge/Version-v1.1.0-blue.svg)](./CHANGELOG.md)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](../../LICENSE)
[![Category](https://img.shields.io/badge/Category-Presentation-Newspaper-green.svg)](../../README.md)

> **一句話介紹**：將任何新聞或專欄排版成《經濟日報》風格的經典單頁 PPTX 簡報：大標題、副標、記者行、雙欄內文與關鍵資訊框。

---

## 🌟 為什麼需要這個技能？（解決的核心痛點）

1. **截圖畫質模糊**：直接放新聞截圖字體模糊且無法投影或編輯文字。
2. **單頁版面文字溢出**：長篇新聞塞進單頁投影片常導致字體過小或文字超出邊界。
3. **缺乏視覺權威感**：缺少報紙經典的報頭、版次、記者行與雙欄排版氣勢。

## 🛠️ 核心工作流程與規範

1. **智能解析文章**：自動提取報社名稱、版次日期、記者行、主標題（雙行）、副標題與內文。
2. **版面配平演算**：將內文智能平均分配至左右雙欄，確保兩欄高度一致。
3. **提煉右側焦點框**：自動提取 3 點關鍵數據或引言，渲染獨立醒目的焦點卡片。
4. **生成可編輯 PPTX**：使用 Node.js / pptxgenjs 產出向量高解析 .pptx 簡報。

## 🕳️ 踩坑紀錄與避坑指南（Lessons Learned）

在開發與使用本技能時，我們總結了以下常見實戰地雷與最佳解法：

### ❌ 常見坑點：標題字數過長導致折行重疊
* **問題現象**：主標第一行嚴格限制 12 字內、第二行 14 字內，超出自動精準截斷提煉。
* **避坑解法**：依本技能標準規範執行。

### ❌ 常見坑點：雙欄文字長度懸殊導致左滿右空
* **問題現象**：內建平衡演算法，依標點符號自然切分雙欄段落。
* **避坑解法**：依本技能標準規範執行。

### ❌ 常見坑點：投影時米黃報紙底色偏暗
* **問題現象**：背景色精準調校為高對比 `#FAF7F0`，確保老舊投影機依然字字清晰。
* **避坑解法**：依本技能標準規範執行。
