# 版本紀錄 (Changelog)

本專案遵循 [Semantic Versioning](https://semver.org/lang/zh-TW/) 版本規範。

---

## [v1.2.0] - 2026-09-17

### 🚀 新增 (Added)
* 新增三組高頻觸發關鍵詞：`專欄文章排版`、`精選文章排版`、`文章排版`。
* 新增開源技能庫文件，包含完整 `README.md`、`CHANGELOG.md` 與 `TROUBLESHOOTING.md` 踩坑經驗庫。

### ⚡ 最佳化 (Optimized)
* 強化桌面端與平板端的置中 App 容器排版（`max-w-lg`），提升寬螢幕閱讀沉浸感。
* 最佳化 Swiper 分頁指示器與前後切換按鈕的點擊回饋效果。

---

## [v1.1.0] - 2026-09-17

### ✂️ 重構與簡化 (Refactored & Simplified)
* **移除多餘冗餘功能**：完全移除傳統「桌面演講簡報模式」與「互動利差試算小工具」，消除功能過載（Feature Creep）。
* **聚焦雙模式核心**：確立「📱 重點速讀」與「📜 全文閱讀」雙切換 Tab，介面極致純粹。
* **頂部導覽列精簡**：消除多餘按鈕，僅保留媒體出處徽章、文章標題、專欄作者與模式切換鍵。

---

## [v1.0.0] - 2026-09-17

### 🎉 初始發布 (Initial Release)
* **首創雙模式架構**：
  - 模式一：手機優先 Swiper.js 滑動卡片（6 頁結構：封面 ➔ 盲點 ➔ 數據 ➔ 反常 ➔ 行動 ➔ 金句）。
  - 模式二：典雅直式全文閱讀（完整收錄原專欄每一字每一句）。
* **視覺與字型標準**：整合 Tailwind CSS、Noto Serif TC（大標/金句）與 Noto Sans TC（內文）。
* **自動化部署連動**：支援一鍵建立 GitHub 公開倉庫並自動啟用 GitHub Pages。
