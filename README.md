## 📦 安裝與使用方式

### 1. 使用 Claude Code CLI 安裝

在您的終端機中執行：

```bash
# 安裝特定單一技能（例如：專欄速讀網頁）
claude skills add garfiwang/claude-skills --path 05-html-slides/article-card-page

# 安裝繁中去 AI 味技能
claude skills add garfiwang/claude-skills --path 01-content-creation/speak-human-tw

# 安裝問大師品牌簡報技能
claude skills add garfiwang/claude-skills --path 04-pptx/wendashi-pptx
```

### 2. 在 Google Antigravity 中使用

直接將本 repo Clone 至您的專案目錄或自訂技能路徑：

```bash
git clone https://github.com/garfiwang/claude-skills.git ~/.gemini/skills/
```

或將各資料夾中的 `SKILL.md` 複製至專案 `.agents/skills/` 內即可即時載入。

## 🔖 版本規範與踩坑指南標準 (Standard)

本技能庫每個 Skill 均嚴格遵循以下標準化結構：

1. **`README.md`**：核心特色、解決痛點、觸發關鍵詞、工作流程與依賴。
2. **`CHANGELOG.md`**：遵守 [SemVer](https://semver.org/lang/zh-TW/)，記錄每次升級內容。
3. **`TROUBLESHOOTING.md`**：記載實戰中發現的邊界地雷、格式問題與最佳防禦方案。
4. **`SKILL.md`**：AI Agent 執行本體，包含完整 YAML Frontmatter 描述。
